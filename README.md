# UrbanCart – Retail Sales & Profitability Dashboard

## 📌 About the Project

UrbanCart is an interactive Retail Sales & Profitability Dashboard created using Tableau. It helps analyze sales, profit, customers, categories, regions and state-wise performance.

## 🎯 Objective

The main objective is to create an interactive dashboard for analyzing retail sales and profitability using Tableau visualizations.

## 🛠️ Tools & Technologies

- Tableau Desktop
- CSV Dataset
- Data Visualization
- Dashboarding
- Calculated Fields
- Map Visualization
- Customer Clustering

## 📊 Dataset

- Dataset Name: UrbanCart_Sales.csv
- Number of Records: 800
- Source: Fictional/Sample Dataset created for academic project

## 📈 Dashboard Features

- Profit Ratio
- Monthly Sales Trend
- Region-wise Sales Analysis
- Top Customers by Sales
- Customer Segmentation
- Discount vs Profit Analysis
- State-wise Sales Map
- Sales by Category
- Interactive Category and Region Filters

## 🧮 Calculated Field

### Profit Ratio

SUM([Profit]) / SUM([Sales])
